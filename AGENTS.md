# Gstack Integration

This project uses gstack for web browsing and specialized skills. Always use the `/browse` skill from gstack for all web browsing tasks. Never use `mcp__claude-in-chrome__*` tools.

## Troubleshooting

If gstack skills aren't working, run: `cd .Codex/skills/gstack && ./setup` to build the binary and register skills.
